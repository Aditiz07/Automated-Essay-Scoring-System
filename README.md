# Automated-Essay-Scoring-System
comparative analysis of BERT, RoBERTa and DistilBERT
This work sheds light on how BERT, RoBERTa and DistilBERT 
transformer models actually would extract features from text and 
have a context understanding to predict the scores of essays. To 
evaluate the effectiveness of such models, the evaluation included 
the most useful and important performance measures-the 
Quadratic Weighted Kappa (QWK) and Earth Mover’s Distance 
(EMD). Ultimately, this study entails an examination on how 
reliable, consistent, and scalable transformer models are for AES 
in the effort of reducing so much human effort while maintaining 
a quality and fair grading.
